อย.อยุธยาเรียนรู้การวางยุทธศาสตร์การศึกษา
แผนปี 2570หน้าแรกเส้นทางเรียนรู้ร่าง 2571–2575โครงการคลังความรู้เครื่องมือแลกเปลี่ยน

ใช้งานอย่างเข้าใจ

ข้อมูลส่วนบุคคล
และการเข้าถึงเว็บไซต์

เก็บข้อมูลเท่าที่จำเป็น เปิดเผยวิธีทำงาน และไม่ให้เครื่องมือเรียนรู้กลายเป็นพื้นที่เก็บข้อมูลผู้เรียนรายบุคคล

1. การอ่านเว็บไซต์

ชุดเว็บไซต์นี้ไม่มีระบบสมัครสมาชิก ไม่มีตัวติดตามโฆษณา ไม่มีเครื่องมือวิเคราะห์ผู้เข้าชม แบบอักษร Sarabun โหลดจากไฟล์ในชุดเว็บ และไม่เรียกแบบอักษรหรือสคริปต์จากบริการภายนอก เมื่อเปิดผ่าน https://ayeduplan1.thamdee.com ผู้ให้บริการโฮสติ้งและเครือข่ายอาจประมวลผลข้อมูลการเชื่อมต่อตามนโยบายของตน เว็บไซต์จึงไม่อ้างว่าไม่มีการประมวลผลข้อมูลใด ๆ เลย

2. แบบประเมินและใบงาน

คำตอบแบบประเมินจะอยู่ในหน่วยความจำของหน้าที่เปิดอยู่จนกว่าจะปิดหรือเปลี่ยนหน้า หากกด “บันทึกผลไว้บนอุปกรณ์นี้” จะใช้พื้นที่เก็บข้อมูลของเบราว์เซอร์เฉพาะเว็บไซต์ (Local storage — ที่เก็บข้อมูลบนอุปกรณ์) โดยไม่มีการส่งคะแนนให้ผู้จัดทำ

ผลที่บันทึกไม่มีการเข้ารหัสเฉพาะแอป ผู้ใช้เครื่องเดียวกันอาจเปิดดูได้ จึงควรล้างผลเมื่อใช้เครื่องสาธารณะหรือเครื่องร่วมกัน การล้างข้อมูลเว็บไซต์ในเบราว์เซอร์อาจทำให้ผลสูญหาย ใบงานและข้อความแลกเปลี่ยนไม่ได้บันทึกถาวรอัตโนมัติ

ใช้ปุ่มล้างคำตอบในหน้าแบบประเมินเพื่อลบข้อมูลเฉพาะแบบประเมินนี้ ไฟล์ผลที่คุณดาวน์โหลดแล้วต้องลบจากอุปกรณ์เอง เว็บไซต์ไม่สามารถเรียกคืนหรือลบไฟล์เหล่านั้น

3. การส่งอีเมลและบริการภายนอก

ปุ่มเตรียมอีเมลใช้แอปอีเมลของคุณ ไม่ส่งข้อความอัตโนมัติ เมื่อคุณส่งจริง ผู้รับจะเห็นที่อยู่อีเมลและเนื้อหาที่ส่งตามการทำงานของบริการอีเมล ผู้จัดทำใช้เพื่อพิจารณาข้อเสนอและตอบกลับ ไม่ถือเป็นการอนุญาตให้เผยแพร่ต่อสาธารณะ หากต้องการให้ลบข้อความที่ส่งถึงผู้จัดทำ โปรดติดต่อ burapatis@gmail.com โดยการจัดการในระบบผู้ให้บริการอีเมลอาจมีเงื่อนไขแยกต่างหาก

ลิงก์ภายนอก รวมถึงกระดาน GitHub Discussions หากเปิดใช้งาน จะอยู่ภายใต้นโยบายของบริการนั้น ไม่ควรส่งข้อมูลเด็ก ข้อมูลสุขภาพ หรือข้อมูลอ่อนไหวผ่านช่องทางเหล่านี้

4. การเข้าถึงเนื้อหา

ออกแบบให้ใช้แป้นพิมพ์ได้ มีลิงก์ข้ามเมนู ป้ายกำกับช่องกรอก จุดโฟกัสที่มองเห็น ข้อความแทนภาพสไลด์พร้อมคำบรรยาย รูปแบบหน้าจอขนาดเล็ก และรูปแบบพิมพ์ ตารางกว้างเลื่อนในกรอบได้ เนื้อหาอ่านและดาวน์โหลดได้โดยไม่ต้องเปิด JavaScript แต่เครื่องมือโต้ตอบต้องเปิดใช้งาน

แนวทางอ้างอิงคือ หลักเกณฑ์การเข้าถึงเนื้อหาเว็บ WCAG 2.2 ยังไม่ได้รับรองการผ่านเกณฑ์ทั้งหมดจากผู้ตรวจอิสระ และไฟล์ต้นฉบับที่ดาวน์โหลดอาจมีข้อจำกัดด้านการเข้าถึงต่างจากหน้าเว็บ

5. แจ้งปัญหา

หากอ่านตารางไม่ได้ ใช้แป้นพิมพ์ติดขัด พบลิงก์เสีย หรือต้องการรูปแบบเนื้อหาอื่น โปรดแจ้งชื่อหน้า ลักษณะปัญหา และอุปกรณ์ที่ใช้ โดยไม่จำเป็นต้องแนบข้อมูลส่วนบุคคล ที่ burapatis@gmail.com
